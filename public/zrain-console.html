FEATURES / 02

Small layer. Useful details.

No app duplication. Zrain Console loads each product from its own existing web address.

01 / VIEWS

Mobile and Desktop

Switch between a mobile-sized viewport and a scaled desktop viewport without resetting the app.

02 / CONTROLS

Preview controls

Refresh, fullscreen, close, or open the original website in a separate tab.

03 / DISCOVERY

One familiar experience

The same preview is used for games, web apps and developer showcases.

04 / INDEPENDENCE

Apps remain separate

The viewer does not merge authentication, databases, or product backends.

HOW WE BUILT IT / 03

Implemented in the Ecosystem.

01. A product button selects a known Console ID.

<button data-console="memory-rush">
  Play Now
</button>

02. The Console looks up that product and opens its original web edition.

03. Visitors use the viewer, or Open in new tab when an app forbids embedding.

Built with

Vanilla JavaScript, HTML, CSS, browser <dialog> and <iframe>. The published product directory is served by the existing Cloudflare Worker and KV storage.

There is no extra server, separate user account or paid infrastructure for Zrain Console.

See the production implementation ↗

Embedding limitation: Some external websites and sign-in providers forbid iframe previews. Zrain Console respects those restrictions and provides Open in new tab. The Zrain UI showcase has a same-origin local preview.
